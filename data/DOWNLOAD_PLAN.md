## Execution after approval

1. Establish exact file URLs or S3 keys and byte sizes. Stop if any selected file exceeds 50 MB or any selected investigation subset exceeds 200 MB. No recursive whole-bucket or whole-investigation sync.
2. Download only the approved allowlist into raw/<dataset>/; record source URL/key, byte size, SHA-256, actual download date, and source version. Exclude media, archives, raw sensor histories and large CFD field dumps. Workbooks may contain embedded images, but no image files will be separately fetched.
3. Clean source files with one reproducible script per dataset. Preserve workbook sheet and row, and PDF page provenance. Never reconstruct tables from plotted curves.
4. Write tidy per-dataset tables, schema mappings, unit conversions, dropped-row reasons, outcome balance, and measured ranges. Combine only compatible, source-supported test records.
5. Rebuild in a fresh raw/output directory, compare output hashes, spot-check up to five source rows per dataset (all rows if fewer than five), and report completeness and actual ranges. Keep data/ below 10 MB.
6. Commit each processed dataset separately. This workspace currently has no Git repository or configured remote; initialize local version control when processing starts. A GitHub destination has not been supplied.

Approval requested: the listed individual-file subsets only. Unverified alternate files, new linked files and oversized selections remain on hold.
